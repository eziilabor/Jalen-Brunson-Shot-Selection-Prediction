# Jalen-Brunson-Shot-Selection-Prediction
This project was made out of the interest of the NBA playoffs to demonstrate the use XGBoosting to learn the data of NBA API to predict the shots and performance of star player Jalen Brunson.

By the time designing this project, the New York Knicks and the Cleveland Cavaliers are advancing to the Eastern Conference Finals. With that, I have deciced to create a prediction model on New York Knicks' starting point guard, Jalen Brunson.

The goal of this project is to predict whether Jalen Brunson makes or misses a shot based on shot location, shot type, shot zone, and game context.


## Technologies
- Python
- Pandas
- Scikit-learn
- XGBoost
- NBA API
- Matplotlib

## Results
- Accuracy: 57.9%
- ROC-AUC: 0.627
